# @ergots/transaction

Pure-TypeScript Ergo transaction wire codec + validation; browser-clean; depends on `@ergots/scorex` + `@ergots/ergoscript`.

Parses and serializes Ergo `UnsignedTransaction` and `ErgoTransaction` wire bytes, validates structural invariants, and computes the signing message (transaction byte payload for Schnorr proofs). Validated byte-for-byte against fixtures generated from the JVM sigma-state reference.

## Status

Phase 1 (wire codec) in progress.

## Browser compatibility

Runs unchanged in evergreen browsers and Node >= 20. No `Buffer`, no `node:crypto`, no dynamic Node built-ins, no WASM. ESM-only.

## What this package does NOT do

- **Signing.** Key management and Schnorr signature generation are out of scope; this package produces the byte payload that is signed.
- **Transaction construction.** Box selection, fee calculation, and token change are not in scope.
- **Node communication.** Submission to the Ergo network is handled by calling a conformant Ergo node REST endpoint directly — no HTTP client is included here.

## Reference implementation

Clean-room TypeScript port of the Ergo JVM transaction serializer (`sigma-state`). Validated byte-for-byte against fixtures generated by the Rust reference.

See [facts/transaction.md](../../facts/transaction.md) for the load-bearing interface contract (written when phase 1 completes).
